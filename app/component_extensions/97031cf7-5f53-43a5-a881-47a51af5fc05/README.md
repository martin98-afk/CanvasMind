# LTX2 专用调度器

## 简介

生成 LTX2 优化的时间步序列（Sigmas），支持偏移拉伸。该组件专为 LTX 视频扩散模型设计，提供灵活的时间步调度策略。

## 特性

- **Shift 偏移计算**：基于 token 数量动态计算最优偏移值
- **Sigma 拉伸**：支持对时间步进行拉伸调整，优化生成质量
- **动态步数**：可配置推理步数（默认20步）
- **Latent 感知**：支持自动检测 latent 大小以调整偏移

## 输入

| 端口 | 名称 | 类型 | 说明 |
|------|------|------|------|
| 输入 | LATENT(可选) | LATENT | latent张量，用于自动计算token数量 |

## 输出

| 端口 | 名称 | 类型 | 说明 |
|------|------|------|------|
| 输出 | SIGMAS | SIGMAS | 优化的时间步序列 |

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 步数 | 整数 | 20 | 推理步数 |
| Max Shift | 浮点数 | 2.05 | 最大偏移值 |
| Base Shift | 浮点数 | 0.95 | 基础偏移值 |
| 拉伸(Stretch) | 布尔 | True | 是否启用sigma拉伸 |
| 终端值 | 浮点数 | 0.1 | 拉伸后的终端sigma值 |

## 使用场景

适用于 LTX 视频生成工作流中，需要精细控制去噪时间步的场景。通过调整 shift 和 stretch 参数，可以平衡生成速度与质量。
