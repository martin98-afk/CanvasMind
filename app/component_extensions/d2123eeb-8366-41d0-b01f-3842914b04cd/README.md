| 属性 | 值 |
|------|-----|
| 名称 | LTX2模型配置器 |

## 组件简介

本组件为 CanvasMind 平台中的 LTX2 模型扩展节点，主要用于为 LTX2 模型应用**动态 Shift 修正**。这是 LTX2 模型能够生成高质量视频的关键配置步骤。

## 功能说明

### 核心功能

- **噪声掩码提取**：从 Latent 数据中提取噪声掩码信息
- **默认掩码生成**：当输入不含噪声掩码时，自动生成全白掩码（默认全部处理）
- **设备兼容**：自动处理 CUDA/CPU 设备，确保跨平台兼容

### 适用场景

本组件适用于基于 LTX2 模型的视频生成工作流，配合 ComfyUI 节点使用。

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| latent | Latent | 是 | 输入的 Latent 数据，包含样本和可选的噪声掩码 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| noise_mask | Tensor | 处理后的噪声掩码张量，形状为 (batch, 1, latent_length, 1, 1) |

## 使用示例

```python
import torch
from get_noise_mask import get_noise_mask

# 构造示例 Latent 数据
latent = {
    "samples": torch.randn(1, 4, 32, 1, 1),  # B, C, L, H, W
    "noise_mask": None  # 可选，如不提供则自动生成全白掩码
}

# 获取噪声掩码
noise_mask = get_noise_mask(latent)
print(f"输出掩码形状: {noise_mask.shape}")
```
