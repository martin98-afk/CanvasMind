# SAM3 统一分割器

> **Segment Anything Model 3** - 二合一智能分割节点

这是一个二合一节点，集成了 **文本提示分割 (Grounding)** 和 **交互式点击分割 (Segmentation)**。基于 Meta 的 SAM3 模型，支持通过文本描述或点击交互精确分割图像中的目标对象。

---

## ✨ 功能特性

- **双模式分割**：文本提示 + 交互式点击/框选
- **高精度分割**：Meta SAM3 核心算法，边缘精细
- **零样本分割**：无需训练即可分割任意类别对象
- **多掩码输出**：支持生成多层级掩码，效果更好

---

## ⚙️ 属性参数

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| **mode** | 枚举 | **工作模式切换**。<br>• `Text Grounding`: 通过文本描述查找对象。<br>• `Interactive`: 通过点/框坐标分割对象。 |
| **text_prompt** | string | (仅文本模式) 输入描述，如 `"red car"`, `"face"`, `"cat"`, `"person dog"`。支持多目标分割。 |
| **confidence** | float | (仅文本模式) 置信度阈值 (0.0-1.0)。默认 `0.2`。值越低召回率越高，但可能包含误检。 |
| **box_input** | string | (仅交互模式) **边界框坐标**。格式为字符串 `"x,y,w,h"` (归一化 0-1)。<br>示例: `"0.5,0.5,0.2,0.2"` (图像中心 20% 大小的区域)。 |
| **point_input** | string | (仅交互模式) **点击点坐标**。格式为字符串 `"x,y"` (归一化 0-1)。<br>示例: `"0.5,0.5"` (点击图像正中心)。 |
| **multimask** | boolean | (仅交互模式) 是否生成多层级掩码。`True` 效果通常更好，输出多个候选掩码。 |

---

## 📝 输出

| 输出名 | 类型 | 说明 |
| :--- | :--- | :--- |
| **mask** | IMAGE | 分割后的黑白遮罩 (H,W,1)，可直接用于后续处理 |
| **image** | IMAGE | 带有分割结果可视化覆盖的原图预览 |
| **json_boxes** | JSON | 检测到的边界框数据，包含坐标和置信度信息 |

## 💡 使用示例

### 模式一：文本提示分割 (Text Grounding)

```
mode: "Text Grounding"
text_prompt: "person"          # 要分割的对象描述
confidence: 0.25               # 置信度阈值
```

**常见 text_prompt 示例：**
| 场景 | 提示词 |
| :--- | :--- |
| 分割人物 | `"person"`, `"people"`, `"man woman"` |
| 分割动物 | `"cat"`, `"dog"`, `"bird"` |
| 分割车辆 | `"car"`, `"truck"`, `"bicycle"` |
| 分割物体 | `"book"`, `"cup"`, `"phone"` |
| 分割部位 | `"face"`, `"hand"`, `"eye"` |

### 模式二：交互式分割 (Interactive)

#### 点击分割
```
mode: "Interactive"
point_input: "0.5,0.5"         # 点击图像中心
multimask: true                # 生成多个候选掩码
```

#### 框选分割
```
mode: "Interactive"
box_input: "0.3,0.3,0.4,0.5"   # 左上角 (0.3,0.3)，宽 0.4，高 0.5
multimask: false
```

#### 点击 + 框选组合
```
mode: "Interactive"
point_input: "0.5,0.5"         # 点击点
box_input: "0.3,0.3,0.4,0.5"  # 边界框
multimask: true
```

## 🗺️ 坐标说明

- 坐标必须是 **0.0 到 1.0** 之间的浮点数 (归一化坐标)
- `(0, 0)` 是图像左上角，`(1, 1)` 是图像右下角
- **不需要手动计算像素值**，模型会自动根据图片分辨率缩放

```
坐标示意图：
┌─────────────────────────────┐
│ (0,0)                       │
│     ■ point                 │
│           ┌─────────┐       │
│           │  box    │       │
│           │ (x,y)   │       │
│           └─────────┘       │
│                       (1,1) │
└─────────────────────────────┘
```

## ⚠️ 注意事项

1. **首次运行**：模型较大，首次加载可能需要下载权重，请确保网络畅通
2. **显存要求**：SAM3 模型较大，建议显存 ≥ 8GB
3. **置信度调节**：
   - 漏检 → 降低 confidence (如 0.1)
   - 误检 → 提高 confidence (如 0.5)
4. **多目标分割**：text_prompt 支持多类别，如 `"person dog cat"`
5. **掩码选择**：multimask=True 时会输出多个掩码，默认取第一个

## 🔧 进阶技巧

### 1. 提高分割精度

- **组合使用点击和框选**：同时提供 point_input 和 box_input 可提高精度
- **多次点击**：使用 multimask=True 获取多个候选掩码，选择最佳结果
- **调整置信度**：复杂场景可降低 confidence 到 0.1-0.15

### 2. 处理复杂图像

- **多目标分割**：使用 `"object1 object2 object3"` 格式同时分割多个类别
- **部分分割**：先框选目标区域，再使用点击精确分割
- **边缘优化**：使用后处理节点（如 Blur、Matting）优化边缘

### 3. 批量处理技巧

- **统一提示词**：对同类图像使用相同的 text_prompt
- **固定参数**：确定最佳参数后固定使用，提高效率
- **预处理**：预先裁剪图像到目标区域，减少误检

## ❓ 常见问题解答 (FAQ)

### Q1: 首次运行很慢怎么办？
> SAM3 模型较大，首次加载需要下载权重（约 375MB）。建议首次运行时保持网络畅通，或手动下载模型到缓存目录。

### Q2: 分割结果不准确？
> - 检查 text_prompt 是否正确拼写<br>
> - 尝试降低 confidence 值（如 0.1-0.15）<br>
> - 对于小目标，建议使用 Interactive 模式<br>
> - 使用更精确的 point/box 坐标

### Q3: 显存不足怎么办？
> - 使用更小的输入分辨率<br>
> - 关闭 multimask 选项<br>
> - 批量处理时减少 batch size<br>
> - 尝试使用轻量级模型（如 sam_vit_b）

### Q4: 文本模式无法分割自定义物体？
> SAM3 的 Grounding 模式依赖预训练的词汇表。对于自定义物体，建议使用 Interactive 模式手动分割，或使用自定义分割模型。

### Q5: 输出多个掩码如何选择？
> - 第一个掩码通常是最大/最完整的<br>
> - 可以添加掩码选择节点手动选择<br>
> - 或使用后处理节点合并多个掩码

### Q6: 坐标填了多少才合适？
> 坐标范围是 0-1（归一化）：<br>
> - 0.5, 0.5 表示图像正中心<br>
> - 0.2, 0.2 表示左上角附近<br>
> - 建议使用画图工具查看坐标后填入

## 🔬 技术原理简介

### SAM3 核心架构

SAM3 (Segment Anything Model 3) 是 Meta 推出的新一代分割模型，主要改进包括：

1. **提示编码器**：支持文本、点、框等多种提示方式
2. **掩码解码器**：高效生成精确的分割掩码
3. **零样本能力**：无需训练即可分割新类别

### 文本分割流程 (Grounding)

```
图像 → 视觉编码器 → 特征图
文本 → 文本编码器 → 特征向量
           ↓
      跨模态匹配 → 定位目标区域
           ↓
      掩码生成器 → 输出分割掩码
```

### 交互分割流程

```
图像 → 视觉编码器 → 特征图
点/框 → 提示编码器 → 提示特征
           ↓
      掩码解码器 → 精细掩码
```
