# CLIP文本编码器

## 组件概述

| 属性 | 值 |
|------|-----|
| 名称 | CLIP文本编码器 |
| 版本 | 1.0.0 |
| 分类 | comfyui节点/基础节点 |
| 作者 | black |

## 功能说明

CLIP文本编码器是ComfyUI工作流中的核心组件，用于将文本提示词转换为CLIP模型可处理的 conditioning（条件控制）向量。该组件是AI图像生成工作流的关键节点，用于：

- 将用户输入的文本提示词编码为向量表示
- 生成用于引导图像生成的条件控制信号
- 支持正向和负向提示词的 conditioning 输出

## 端口说明

### 输入端口

| 端口名 | 标签 | 类型 | 说明 |
|--------|------|------|------|
| clip | CLIP | OBJECT (CLIP) | 必填，连接CLIP模型节点 |

### 输出端口

| 端口名 | 标签 | 类型 | 说明 |
|--------|------|------|------|
| conditioning | 条件控制 | OBJECT (Conditioning) | 编码后的条件控制向量，可连接到采样器 |

## 属性说明

| 属性名 | 标签 | 类型 | 默认值 | 说明 |
|--------|------|------|--------|------|
| text | 提示词 | MULTILINE | (空) | 要编码的文本内容，支持多行 |

## 使用示例

```
[CLIP模型加载器] --> [CLIP文本编码器] --> [KSampler/采样器] --> [VAE解码器] --> [图像输出]
```

### 典型工作流

1. **CLIP模型加载器** - 加载预训练的CLIP模型
2. **CLIP文本编码器** - 输入提示词，输出conditioning
3. **KSampler** - 使用conditioning进行采样生成
4. **VAE解码器** - 将潜在空间向量解码为图像

## 注意事项

- 必须先连接CLIP模型才能正常工作
- 文本提示词支持中英文输入
- 多行文本可用于描述更复杂的场景
- 输出的conditioning可同时用于正向和负向提示词

## 依赖项

- CLIP模型（通过CLIP模型加载器提供）
- ComfyUI基础框架
