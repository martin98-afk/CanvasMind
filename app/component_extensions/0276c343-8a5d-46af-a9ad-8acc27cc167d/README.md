## 组件描述

调用阿里云 **DashScope Wan 2.6** 模型生成图像的 Workflow GUI 组件。支持文本到图像生成，可广泛应用于创意设计、内容创作、AI 应用等领域。

---

## 功能特性

| 特性 | 说明 |
|------|------|
| 🎨 **文生图生成** | 将文本描述转换为高质量图像 |
| 📐 **多种分辨率** | 支持正方形、竖版、横版多种比例 |
| 🔄 **提示词扩展** | 自动优化提示词，提升生成效果 |
| 💧 **水印控制** | 可选添加 DashScope 水印标识 |
| 🔀 **多模型支持** | 兼容 Wan 2.6、Z-Image、 WanX 等模型 |

---

## 支持的模型

| 模型名称 | 说明 | 适用场景 |
|----------|------|----------|
| `wan2.6-t2i` | Wan 2.6 文本转图像（**默认**） | 通用图像生成，质量优先 |
| `z-image-turbo` | 快速图像生成 | 需要快速响应的场景 |
| `wanx-v1` | WanX V1 版本 | 特定风格兼容 |

> 💡 **模型选择建议**：
> - 追求最佳质量 → 使用 `wan2.6-t2i`
> - 需要快速迭代 → 使用 `z-image-turbo`

## 输入端口

| 端口名称 | 标签 | 类型 | 必填 | 说明 |
|----------|------|------|------|------|
| `prompt` | 正向提示词 | TEXT | ✅ | 描述想要生成的图像内容，建议详细具体 |
| `negative_prompt` | 反向提示词(可选) | TEXT | ❌ | 描述不想出现在图像中的元素 |

### 提示词技巧

**正向提示词示例**：
```
一只可爱的橘色小猫躺在柔软的毛毯上，阳光从窗户斜射进来，
毛发光泽细腻，眼神明亮温柔，超高分辨率，写实风格
```

**反向提示词示例**：
```
模糊、变形、低质量、变形、畸形、噪点、摩尔纹、
水印、文字、边框、丑陋、恐怖
```

## 属性配置

| 属性名 | 标签 | 类型 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `api_key` | DashScope API Key | TEXT | - | **必填**，阿里云 DashScope API 密钥 |
| `model` | 模型名称 | CHOICE | wan2.6-t2i | 选择使用的图像生成模型 |
| `size` | 分辨率 | CHOICE | 1024×1024 | 输出图像的宽×高 |
| `prompt_extend` | 提示词自动扩展 | BOOL | True | 启用后自动优化扩展输入提示词 |
| `watermark` | 添加水印 | BOOL | False | 是否在图像右下角添加水印 |

### 分辨率选项

| 选项 | 尺寸 | 宽高比 | 推荐使用场景 |
|------|------|--------|--------------|
| `1024*1024` | 1024×1024 | 1:1 | 方形图、头像、社交媒体封面 |
| `1280*1280` | 1280×1280 | 1:1 | 高清方形图 |
| `720*1280` | 720×1280 | 9:16 | 竖版海报、手机壁纸 |
| `1280*720` | 1280×720 | 16:9 | 横版图片、横幅 |

## 使用示例

### 1. 获取 API Key

1. 登录 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/)
2. 在「API-KEY 管理」中创建或查看已有 API Key
3. 将 API Key 填写到组件的 `api_key` 属性中

> ⚠️ **安全提示**：请妥善保管 API Key，避免泄露！

### 2. 基础工作流

```
[文本输入节点] ──prompt──> [Wan 2.6 文生图] ──output_image──> [图像显示/保存节点]
                                      │
                        可选: [文本输入节点] ──negative_prompt──>
```

### 3. 典型使用场景

**场景 A：生成艺术插画**
```
prompt: "一幅中国水墨山水画，云雾缭绕的山峰，飞鸟掠过"
model: wan2.6-t2i
size: 1280*720
```

**场景 B：产品概念图**
```
prompt: "极简风格白色无线蓝牙耳机，金属质感，现代设计"
negative_prompt: "文字、水印、模糊、噪点"
model: wan2.6-t2i
size: 1024*1024
```

**场景 C：社交媒体配图**
```
prompt: "一只柯基犬在草地上奔跑，午后阳光温暖，摄影风格"
prompt_extend: True
size: 720*1280
```

## 技术实现

| 项目 | 值 |
|------|-----|
| **API 端点** | `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` |
| **认证方式** | Bearer Token (API Key) |
| **请求协议** | HTTPS REST API |
| **依赖库** | `requests`, `Pillow`, `numpy` |
| **超时设置** | API 请求 60 秒，图片下载 30 秒 |

### 请求流程

```
1. 构建 HTTP POST 请求
   └─ 包含 Authorization Header
   └─ JSON Body: model, input.messages, parameters

2. 发送请求到 DashScope API

3. 解析响应
   └─ 检查状态码和错误信息
   └─ 提取 image URL

4. 下载生成的图片
   └─ 从 image URL 获取图片数据
   └─ 转换为 PIL Image 对象

5. 返回结果
   └─ output_image: PIL Image
```

## 错误处理

| 错误信息 | 可能原因 | 解决方案 |
|----------|----------|----------|
| `请在属性栏设置 DashScope API Key` | 未配置 API Key | 在属性面板填写有效的 API Key |
| `API 请求失败: [InvalidApiKey]` | API Key 无效或已过期 | 检查 API Key 是否正确，或重新生成 |
| `API 请求失败: [RateLimitExceeded]` | 请求频率超限 | 降低调用频率，或联系阿里云提升配额 |
| `API 请求失败: [QuotaExceeded]` | 配额不足 | 检查账户余额或升级套餐 |
| `API 未返回任何图像数据` | 模型响应异常 | 重试请求，或更换模型尝试 |
| `图片下载失败` | 网络问题或 URL 过期 | 检查网络连接，重试生成 |
