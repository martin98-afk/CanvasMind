# Wan 2.6 图生视频组件

## 组件简介

本组件是一个 **图生视频（Image to Video）** 扩展模块，基于阿里云 **DashScope** 平台的 Wan 2.6 模型实现。通过上传图片并输入视频描述词（Prompt），可自动生成对应的视频内容。

> 📌 **组件版本**: 1.0.0  
> 🔄 **最后更新**: 2026-03-03  
> 👤 **作者**: black

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 🎬 **图生视频** | 上传图片，通过 Wan 模型生成动态视频 |
| 🔊 **音频合成** | 支持可选音频输入，为视频添加背景音乐 |
| ⚡ **异步任务** | 使用 DashScope 异步 API，任务提交后自动轮询 |
| 🎯 **多模型支持** | 支持 `wan2.6-i2v-flash` 和 `wan2.1-i2v-turbo` |
| 📺 **多分辨率** | 支持 480P、720P、1080P 三种分辨率 |

---

## 输入端口

| 端口名 | 标签 | 类型 | 说明 |
|--------|------|------|------|
| `image` | 输入图片 | IMAGE | 要转换为视频的图片 |
| `prompt` | 视频描述词 | TEXT | 描述期望生成的视频内容 |
| `audio_url` | 音频URL(可选) | TEXT | 可选的背景音频链接 |

---

## 输出端口

| 端口名 | 标签 | 类型 | 说明 |
|--------|------|------|------|
| `output_video.mp4` | 生成的视频URL | FILE | Wan 模型生成的视频链接 |

---

## 配置属性

| 属性名 | 标签 | 类型 | 默认值 | 可选值 | 说明 |
|--------|------|------|--------|--------|------|
| `api_key` | DashScope API Key | TEXT | - | - | 阿里云 DashScope API 密钥 |
| `model` | 模型 | CHOICE | wan2.6-i2v-flash | wan2.6-i2v-flash, wan2.1-i2v-turbo | 视频生成模型 |
| `resolution` | 分辨率 | CHOICE | 720P | 480P, 720P, 1080P | 输出视频分辨率 |
| `duration` | 视频时长(秒) | INT | 5 | - | 生成的视频时长 |
| `shot_type` | 镜头类型 | CHOICE | single | single, multi | 镜头切换模式 |
| `prompt_extend` | 提示词扩展 | BOOL | True | - | 是否自动扩展提示词 |

## 使用示例

### 1. 配置 API Key
首次使用前，需在组件属性中配置 **DashScope API Key**：
- 前往 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/) 申请 API Key

### 2. 连接输入
- 将图片节点连接到 `image` 端口
- 在 `prompt` 端口输入视频描述（如：一只猫在草地上奔跑）
- (可选) 在 `audio_url` 端口连接音频URL

### 3. 配置参数
根据需求设置分辨率、时长、镜头类型等参数

### 4. 执行任务
组件将自动提交异步任务并轮询等待视频生成完成

## 技术原理

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  输入图片    │────▶│  图片上传    │────▶│  提交任务   │
└─────────────┘     │ (Base64/URL) │     │ (异步API)   │
                    └──────────────┘     └──────┬──────┘
                                                │
                    ┌──────────────┐             │
                    │  轮询状态    │◀────────────┘
                    │ (每5秒)      │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │  返回视频URL │
                    └─────────────┘
```

## 常见问题

### Q1: 任务提交失败怎么办？
**A**: 检查 API Key 是否正确配置，确保已在 DashScope 控制台开通视频生成服务。

### Q2: 视频生成超时怎么办？
**A**: 任务默认最多等待约 500 秒（5秒 × 100次轮询），如需更长等待时间可修改代码中的 `max_retries` 参数。

### Q3: 支持哪些图片格式？
**A**: 支持 PNG、JPG、JPEG 等常见图片格式，组件会自动转换为 Base64 进行处理。
