# 组件画布市场 - 用户体验优化设计方案

**日期**: 2026-04-17  
**版本**: v1.0  
**优先级**: 用户体验/交互  
**交互风格**: 流畅现代

---

## 1. 设计理念

将组件画布市场从"功能可用"提升到"专业级软件体验"：
- **流畅感**：每个操作都有即时视觉反馈，动画流畅自然
- **信息密度合理**：不拥挤也不空洞，关键信息一目了然
- **容错性**：误操作可撤销，错误信息友好

---

## 2. 视觉设计规范

### 2.1 色彩系统

| 用途 | 颜色 | 说明 |
|------|------|------|
| 主背景 | `#0f0f0f` | 深色背景，更护眼 |
| 卡片背景 | `#1a1a1a` | 卡片默认状态 |
| 卡片悬停 | `#222222` | 悬停时轻微提亮 |
| 边框 | `#2d2d2d` | 微妙边框 |
| 主色调 | `#3b82f6` | 蓝色，用于主要操作 |
| 成功 | `#22c55e` | 安装成功/已同步 |
| 警告 | `#f59e0b` | 有更新/待处理 |
| 错误 | `#ef4444` | 失败/删除 |
| 文字主 | `#ffffff` | 主要文字 |
| 文字次 | `#a1a1a1` | 次要文字/描述 |
| 文字弱 | `#6b6b6b` | 占位符/禁用态 |

- **尺寸**: 最小宽度 320px，高度自适应（最小180px）

- **悬停动画**: 100ms ease-out 向上偏移2px + 阴影增强
- **选中态**: 左边框 3px 主色高亮 + checkbox显示

## 4. 交互设计

### 4.1 搜索

**实时搜索（debounce 300ms）**:
1. 用户输入时显示搜索建议下拉
2. 匹配项高亮显示
3. 支持拼音搜索（首字母和全拼）
4. 搜索历史显示最近5条

**搜索历史**:
- 显示在搜索框下方
- 点击可快速填充
- 删除按钮清除单条
- 设置中可清除全部历史

### 4.2 卡片交互

| 状态 | 视觉效果 |
|------|----------|
| 默认 | 静态展示 |
| 悬停 | 上升2px + 阴影增强 + 显示操作按钮 |
| 选中 | 左侧蓝色边框 + checkbox显示 |
| 安装中 | 进度条覆盖 + 禁用点击 |
| 成功 | 绿色闪烁 → 恢复正常 |
| 失败 | 红色抖动 + toast提示 |

**卡片内操作按钮**:
- 主按钮: 安装/更新/查看（根据状态显示）
- 次按钮: ⋮ 菜单（收藏/详情/删除）

### 4.3 批量操作

**选择模式**:
1. 点击卡片checkbox或长按进入选择模式
2. 底部工具栏滑入显示
3. 显示已选数量和批量操作按钮

**批量操作栏**:
```
┌────────────────────────────────────────────────────┐
│  ○ 已选择 4 项                        [取消] [安装] [上传] │
└────────────────────────────────────────────────────┘
```
- 工具栏从底部滑入 (200ms ease-out)
- 操作完成后滑出

### 4.4 Toast通知系统

替代MessageBox的轻量通知：

| 类型 | 颜色 | 位置 | 持续 |
|------|------|------|------|
| 成功 | `#22c55e` | 底部居中 | 2s |
| 警告 | `#f59e0b` | 底部居中 | 3s |
| 错误 | `#ef4444` | 底部居中 | 4s |
| 进度 | 蓝色+进度条 | 底部居中 | 直到完成 |

### 4.5 页面切换动画

- 标签页切换: 旧内容淡出(100ms) + 新内容淡入(150ms)
- 列表加载: 新卡片逐个stagger进入（间隔50ms）

   - 已安装页的"批量安装"实际调用了`_on_batch_upload()`

## 6. 性能优化

### 6.1 虚拟滚动

当项目超过100个时启用虚拟滚动，只渲染可见区域：
- 上下各渲染5个缓冲项
- 滚动时动态计算可见范围

### 6.2 图片懒加载

- 首屏图片立即加载
- 非可见区域图片占位
- 进入可视区时淡入加载

### 6.3 防抖节流

| 操作 | 防抖/节流 | 时间 |
|------|-----------|------|
| 搜索输入 | 防抖 | 300ms |
| 窗口调整 | 防抖 | 100ms |
| 滚动事件 | 节流 | 16ms (60fps) |

## 7. 错误处理

### 7.1 网络错误

- 首次失败: toast提示"网络波动，重试中..."
- 3次重试后: 显示错误卡片"网络不可用，点击重试"
- 离线检测: 顶部显示横幅"当前离线，部分功能不可用"

### 7.2 操作失败

- 显示具体错误原因
- 提供重试按钮
- 上传失败保留草稿

## 10. 成功标准

1. **流畅度**: 90%的操作在100ms内有视觉反馈
2. **错误率**: 操作失败率 < 1%
3. **可用性**: 新用户无需学习即可完成安装/上传
4. **性能**: 100个组件的列表滚动保持60fps
