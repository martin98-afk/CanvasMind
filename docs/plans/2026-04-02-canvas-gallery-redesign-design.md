# 画布管理界面重构设计方案

## 1. 背景与目标

当前 `WorkflowCanvasGalleryPage` 采用分页浏览画布，用户反馈操作不便。本次重构旨在：

- **去掉分页**：改为无限滚动浏览全部画布
- **视图切换**：支持网格视图和列表视图切换，类似 Windows 资源管理器
- **列表预览**：列表视图下右侧显示选中画布的大预览图和详细信息

## 2. 设计方案

### 2.1 整体布局

```
┌─────────────────────────────────────────────────────────┐
│  [视图切换图标]  搜索框        排序字段 ▼  排序方向 ▲   │
├───────────────────────────────┬─────────────────────────┤
│                               │                         │
│   画布列表/网格               │   大预览图 + 详细信息    │
│                               │   + 操作按钮             │
│                               │                         │
└───────────────────────────────┴─────────────────────────┘
```

### 2.2 顶部栏

| 元素 | 说明 |
|------|------|
| 视图切换按钮 | 图标按钮，切换网格/列表视图 |
| 搜索框 | 拼音搜索画布名称 |
| 排序字段下拉 | 修改时间/创建时间/画布名称 |
| 排序方向按钮 | 升序/降序切换 |

### 2.3 网格视图

- 保持现有 `FlowLayout` 风格
- 卡片形式展示：`WorkflowCard`
- 无限滚动，所有画布在一页内浏览
- 左上角悬浮"+"按钮：新建/导入/模板

### 2.4 列表视图（新增）

- 左右分栏布局
- **左侧列表**：
  - 每行：缩略图(48x48) | 名称 | 修改时间 | 创建时间 | 大小
  - 单击选中行，右侧预览更新
  - 双击或点击"打开"按钮打开画布
  - 悬停显示操作按钮
  - 右键弹出快捷菜单

- **右侧预览面板**：
  - 大预览图（保持宽高比）
  - 详细信息：创建时间、修改时间、大小、路径
  - 操作按钮：[打开] [复制] [重命名] [删除]
  - 无选中时显示"请选择一个画布"

### 2.5 视图切换逻辑

- 切换时保持：搜索关键词、排序规则、滚动位置
- 记住用户偏好：下次打开使用上次视图模式

## 3. 组件清单

### 3.1 新增组件

| 组件 | 说明 |
|------|------|
| `WorkflowListView` | 列表视图主容器 |
| `WorkflowListItem` | 列表单项 |
| `WorkflowPreviewPanel` | 右侧预览面板 |
| `ViewToggleButton` | 视图切换按钮 |

### 3.2 修改组件

| 组件 | 修改内容 |
|------|----------|
| `WorkflowCanvasGalleryPage` | 移除分页逻辑，新增视图切换 |
| `ActionCard` | 保留作为悬浮按钮的功能 |

## 4. 实现计划

### Phase 1: 基础设施
- 创建 `WorkflowListView` 和 `WorkflowPreviewPanel`
- 实现视图切换按钮和状态管理

### Phase 2: 列表视图
- 实现列表数据结构和渲染
- 实现选中高亮和预览联动

### Phase 3: 交互优化
- 右键菜单
- 悬停效果
- 键盘导航支持

### Phase 4: 移除分页
- 移除 `PipsPager`
- 改为无限滚动
- 迁移 `ActionCard` 为悬浮按钮

## 5. 国际化

所有 UI 文本使用 `self.tr()` 处理：
- "网格视图" / "列表视图"
- "创建时间" / "修改时间"
- "请选择一个画布"
- 按钮文本保持现有翻译
